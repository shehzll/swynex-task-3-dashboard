# SWYNEX Task 3: Titanic Survival Analysis Dashboard

## Project Overview
This project presents an interactive Titanic Survival Analysis Dashboard created using Microsoft Power BI as part of my Data Analyst Internship at SWYNEX Technologies.

The dashboard helps users understand passenger survival patterns based on gender, age group, ticket fare, and survival status.

## Tools Used
- Microsoft Power BI
- Power Query
- DAX
- Data visualization

## Key Insights
- Total passengers analyzed: 891
- Passengers who survived: 342
- Overall survival rate: 38.38%
- Female survival rate: 74.20%
- Male survival rate: 18.89%
- Average fare of survivors: 48.40
- Average fare of non-survivors: 22.12

## Dashboard Features
- KPI cards showing passenger count, survivors, survival rate, and average fare
- Survival distribution chart
- Survival rate by gender
- Survival rate by age group
- Average fare comparison by survival status
- Interactive filters for gender, age group, and survival status
